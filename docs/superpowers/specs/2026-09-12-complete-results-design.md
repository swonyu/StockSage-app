6-bit; the first unloaded, the second loaded at 71,680 context. StockSage requires exactly
one inventory entry, so availability/context verification and normal-Quit cleanup fail.
Recognize multiple compatible copies only when every matching entry meets the vetted
profile. Resolve the responding instance across all matching copies, requiring exactly one
instance of that ID. Reject incompatible copies, conflicting/malformed instance metadata,
and ambiguity. Unload only the validated selected instances, never other model keys/files.
